# Security Policy

## Reporting vulnerabilities

Do not report security vulnerabilities in public GitHub Issues.

Send reports to: incontact@terabitlab.com

Include:

- Description of the vulnerability
- Steps to reproduce
- Impact assessment
- Suggested fix (optional)

## What not to send

- Do not send certificates, private keys, or passwords
- Redact all log output before sharing
- Do not include real customer data

## Scope

- Authentication and authorization bypasses
- Private key or certificate exposure
- XML injection, XXE, or signature bypass
- Payment confirmation forgery or replay
- SQL injection, XSS, CSRF
- Information disclosure through logs or diagnostics
