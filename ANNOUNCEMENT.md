# MPay Cultural Voucher WooCommerce Gateway - Now Public

## English

**The first source-available WooCommerce payment gateway for Moldova MPay and Cultural Voucher is now on GitHub.**

After years of production use, TerabitLab is making its MPay integration plugin publicly accessible. This is not a demo, not a skeleton, not a boilerplate. This is the actual gateway that processes Cultural Voucher payments in production - with real SOAP WS-Security, real certificate handling, real idempotent confirmations.

**What you get:**

- Complete WooCommerce payment gateway (29 PHP modules, 7000+ lines)
- Full SOAP server with GetOrderDetails and ConfirmOrderPayment
- WS-Security XML digital signature (sign and verify) with X.509 certificates
- PKCS#12 certificate handling with PHP OpenSSL and CLI fallback
- Cultural Voucher product eligibility and IDNP payer identification
- Idempotent payment confirmation with transient-based locking
- Admin diagnostics, debug console, certificate monitoring, WP-CLI
- Complete bilingual documentation (English and Romanian)
